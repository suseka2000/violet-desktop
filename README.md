# Violet

Приложение для планирования помещений, раскладки стеновых панелей и подготовки
документации. В Violet можно редактировать план, назначать монтаж, смотреть
3D-сборки и выпускать альбомы PDF/DXF и модели STEP. Возможности сборки зависят
от выбранной системы и доступных узлов библиотеки.

## Скачать и установить

Откройте [последний выпуск](https://github.com/suseka2000/violet-desktop/releases/latest)
и выберите установщик для своего компьютера:

- **Windows x64:** `Violet-<версия>-win-x64.exe`.
- **Mac с Apple Silicon (M1 и новее):** `Violet-<версия>-mac-arm64.dmg`.
- **Mac с процессором Intel:** `Violet-<версия>-mac-x64.dmg`.

Обе версии для Mac требуют **macOS 13 или новее**. Python и Node устанавливать
отдельно не нужно. ZIP-файлы для Mac и файлы `violet-update` нужны системе
обновления; для первой установки на Mac выбирайте DMG.

Приложение не подписано платными сертификатами Apple/Microsoft. ОС может
предупредить о неизвестном разработчике или заблокировать запуск в соответствии
со своей политикой безопасности. Violet не отключает защиту ОС.

## Файлы и обновления

DXF и STEP обрабатываются встроенными компонентами. Для прямого импорта DWG
нужен отдельный совместимый конвертер; он не входит в установщик.

Проверить обновления можно в меню **Violet**. Учётная запись GitHub не нужна.
Программа проверяет подпись Ed25519 и контрольную сумму перед установкой.
Это подпись обновления Violet, а не сертификация Apple/Microsoft.

Обновление скачивает пакет приложения целиком. Проекты хранятся отдельно
на компьютере и не заменяются вместе с программой.

## Поддержка и выпуск новых версий

[Инструкция по сборке и обновлениям](docs/desktop-release.md) описывает сборку
Windows/macOS, проверку пакетов, подпись и публикацию выпуска.
**Не публикуйте закрытый ключ подписи обновлений.** Храните его вне репозитория
и сделайте защищённую резервную копию.

Лицензии сторонних компонентов включены в приложение; исходники и поправки
CAD-библиотек находятся в архиве `Violet-<версия>-dependency-sources.zip`
рядом с установщиками. Сторонние библиотеки и материалы сохраняют свои условия
использования: размещение здесь не означает разрешения перелицензировать их.
