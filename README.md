# Violet

Программа для планировки помещений, отделки и выпуска документации.

## Скачать

Установщики для **Windows x64** и **Mac Apple Silicon (M1 и новее)** доступны в [последнем выпуске](https://github.com/suseka2000/violet-desktop/releases/latest).

В установленном приложении используйте меню **Violet → Проверить обновления**. Обновление сохраняет проекты на компьютере. Адрес обновлений не изменился.

Mac Intel больше не поддерживается; прежние установщики доступны только в архиве выпусков.

## О репозитории

Здесь находятся установщики, подписанные манифесты обновлений и сведения о выпусках. Исходники Violet хранятся отдельно в закрытом репозитории.

Автоматические архивы GitHub «Source code» содержат только эту страницу. Архивы исходников сторонних зависимостей приложены к выпускам в соответствии с их лицензиями.
