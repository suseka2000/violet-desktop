Необязательный агент через OpenAI API по явному разрешению пользователя передаёт необходимые данные проекта, текста и изображений в OpenAI. Этот файл фиксирует происхождение, а не заменяет тексты лицензий зависимостей.

Для STEP используется бинарный пакет без VTK, закреплённый в `requirements-cad.txt`; приложение использует возможности Open CASCADE Technology. Перед сборкой распространяемого установщика нужно включить полные лицензии/notices обёрток, ядра и транзитивных библиотек. Запись в этой таблице не заменяет этих файлов. Установленный wheel OCP не содержит собственного отдельного LICENSE в перечне package metadata; нельзя предполагать, что pip автоматически собрал полный комплект уведомлений для будущей поставки.

Неизменённые файлы Noto Sans включены в `backend/documents/fonts` вместе с полным `OFL.txt`. Шрифт встраивается в PDF. Для сборки самостоятельного установщика нужно сохранить license/notices всех транзитивных библиотек, включая PDFium; установка через pip сохраняет их в дистрибутивах.

Изображения, чертежи и узлы пользователя не входят в сторонние зависимости и не публикуются. Мебель/текстуры из OpenPlan3D не копировались. OpenPlan3D исследован как будущий редактор, но его полное приложение не встроено: описанные в `docs/cad-reuse-assessment.md` допуски и модель топологии требуют отдельного адаптера. Текущий узкий SVG-редактор написан для канонической модели, чтобы не терять размеры и назначения.

Прямой DWG и закрытый ODA File Converter не поставляются. Пользователь может сохранить DXF в своей CAD-программе; загрузчик объясняет ограничение DWG, а не маскирует его под успешный импорт.

## Исследовательский инструмент, не включённый в приложение

**GNU LibreDWG 0.14**, лицензия **GPL-3.0-or-later (GPLv3+)**, использован
5 октября 2026 года для локального исследования двух предоставленных DWG.
Первичный источник: [GNU LibreDWG](https://www.gnu.org/software/libredwg/),
загруженный [официальный исходный архив 0.14](https://ftp.gnu.org/gnu/libredwg/libredwg-0.14.tar.xz).
SHA-256 полученного архива:
`62ebb73b984f865960f20ed26619ea5f8789d5e3fd088fa40a2598384da81275`.
Полный текст лицензии сохранён в `COPYING` внутри распакованного исходного дерева.

Исходники и временная локальная сборка находятся только в `tmp/vendor_tools/`,
производные DXF и диагностические логи - в `tmp/vendor_exports/`. Системная
установка не выполнялась. Код или исполняемые файлы LibreDWG не включены в
приложение, `requirements.txt` или штатный загрузчик DWG. Его исходный код не
копировался в `backend/reference_drawing.py`: этот модуль самостоятельно читает
пары кодов уже полученного ASCII DXF и выполняет только потоковую инспекцию.

Экспериментальные производные содержат предупреждения и, для одного DWG, ошибки
конвертера; успешное чтение ezdxf не означает lossless-конверсию. Они не заменяют
ожидаемый нативный DXF и контрольный PDF из CAD. Метаданные происхождения и
диагностика записаны в `resources/vendor/reference-drawings.json`; исходные
пользовательские чертежи не публикуются. Перед возможной поставкой LibreDWG
потребуется отдельно учесть его полный GPLv3+ и notices; текущая запись не
означает включения инструмента в состав продукта.
